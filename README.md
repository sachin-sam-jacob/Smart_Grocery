## 🚀 Overview

**Smart Grocery Shopping** is an AI-powered online grocery platform built using the **MERN stack**. The platform simplifies modern grocery shopping by offering features such as **face-authenticated login, AI-powered recipe generation, dynamic pricing, real-time inventory management**, and **voice-activated assistance**. It caters to multiple user roles including **customers, admins, suppliers**, and **district operation managers**.

---

## ✨ Features

- 🔐 **Face-Authenticated Secure Login**
- 🛒 **Smart Shopping Cart** with real-time updates
- 📦 **Inventory Management** with automated restocking
- 🍽️ **AI-Based Recipe Generation** from cart items
- 💸 **Dynamic Pricing** based on demand, stock, and location
- 🗣️ **Voice Assistant** for hands-free shopping
- 👨‍💼 **Role-based Access** for Admin, Supplier, DOM, and Customer
- 📤 **Order Management**, Supplier Integration & Delivery Scheduling
- 📝 **Product Reviews & Wishlist**
- 🧠 **Personalized Recommendations** using AI

## 🛠️ Setup Instructions

1. Clone the repository  
   ```bash
   git clone https://github.com/<your-username>/smart-grocery.git
   ```

2. Install backend dependencies  
   ```bash
   cd server
   npm install
   ```

3. Install frontend dependencies  
   ```bash
   cd ../client
   npm install
   ```

4. Start the development server  
   ```bash
   npm run dev
   ```
